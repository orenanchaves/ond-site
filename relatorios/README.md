# Relatórios do OND

Padrão desde 20 de setembro de 2026: **todo relatório de análise do site vira um arquivo `.md` nesta pasta**, em vez de ficar só na conversa.

## Regras

- **Nome do arquivo:** `AAAA-MM-DD-assunto.md`, por exemplo `2026-09-20-arquitetura-da-informacao.md`.
- **Começo do arquivo:** título, data, método ou fonte usada, escopo e, quando houver, a tarefa percorrida.
- **Conteúdo:** o retrato antes, os achados, o que foi feito com link para as páginas e o que ficou pendente. Números sempre que der.
- **Nada inventado:** preço, métrica e citação precisam de fonte. Faixa de mercado vai com a data da pesquisa.
- **Sem travessão** no texto, seguindo o padrão de escrita do OND.
- Os arquivos entram no repositório, mas não são páginas do site: ficam fora do sitemap e fora do menu.
